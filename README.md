## 🎯 Objetivo del Proyecto
Este dashboard interactivo transforma datos transaccionales de ventas en **insights estratégicos**. Siguiendo los principios **IBCS (International Business Communication Standards)**, el reporte permite una toma de decisiones ágil, eliminando el ruido visual y enfocándose en las métricas clave de rendimiento (KPIs).

## 📈 Capacidades de Análisis
El dashboard permite filtrar la información por ciudad y navegar a través de cuatro dimensiones clave:
1. **Mapa de Calor:** Visualización de tendencias temporales por línea de producto.
2. **Desglose Operativo:** Ventas por día de la semana para optimización de inventarios.
3. **Análisis de Volumen:** Comparativa de ingresos ($) vs. cantidad de unidades.
4. **Perfil del Consumidor:** Segmentación por género y métodos de pago preferidos.

## 🛠️ Stack Tecnológico
* **Python:** Procesamiento y transformación de datos.
* **Streamlit:** Desarrollo de la interfaz web interactiva.
* **Plotly:** Motor de visualización de gráficos dinámicos.
